ESP32-S3-RLCD-4.2（16 MB Flash / 8 MB PSRAM）通用固件。

- 下载 `glance-esp32s3-v*.zip` 获取完整烧录包，也可单独下载附件。
- `app.bin` 用于已有匹配分区布局的设备升级；操作前请阅读 `FLASHING.md`。
- `factory.bin` 是首次初始化使用的合并镜像，会覆盖 NVS 中的配置和历史。
- `SHA256SUMS` 用于校验包内及单独下载的固件文件。
- 公开固件不含 MQTT 密码或米家绑定密钥；个性化设备请继续使用本地私密配置编译。
- 使用 ESP Rust 1.98.1.0 预发布工具链、ESP-IDF 5.5.3。

CI 完成编译和主机测试；公开镜像不代表逐版本上板验证，也不是在线 OTA 包。
